SQL Performance Explained#

SQL Performance Explained giúp developer cải thiện database performance. Sách tập trung vào SQL — bao quát mọi SQL database lớn mà không sa đà vào chi tiết của riêng một product nào.

Bắt đầu từ nền tảng về indexing và where clause, SQL Performance Explained dẫn developer đi qua mọi thành phần của một SQL statement và chỉ ra những cạm bẫy khi dùng object-relational mapping (ORM) tool như Hibernate.

Các chủ đề được đề cập gồm:#

  • Sử dụng multi-column index
  • Áp dụng SQL function đúng cách
  • Sử dụng LIKE query hiệu quả
  • Tối ưu join operation
  • Clustering data để cải thiện performance
  • Pipelined execution của order by và group by
  • Đạt performance tốt nhất cho pagination query
  • Hiểu scalability của database

Nhờ cấu trúc có hệ thống, SQL Performance Explained vừa là sách giáo khoa vừa là tài liệu tra cứu mà mọi developer nên có trên kệ sách.
